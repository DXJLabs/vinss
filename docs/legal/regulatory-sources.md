# Source Quality Rule

Prefer:

```text
statute / regulation
→ regulator guidance
→ regulator FAQ
→ regulator enforcement
→ reputable secondary analysis
```

Do not base a launch decision only on:

```text
blog;
tweet;
Telegram;
competitor Terms;
AI answer.
```
